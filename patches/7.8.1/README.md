# Patches for OCCT 7.8.1

None. The 7.8.1 releases are built from the unmodified upstream commit pinned in
`versions/7.8.1.env`.

A patch added here is applied by `scripts/fetch_source.sh` in file-name order, is part of
the published source tarball, and is licensed under LGPL-2.1 like OCCT itself. Adding one
requires a new `KERNEL_BUILD` number.
